# Pipl Device Intelligence SDK for iOS

Binary distribution surface for the Pipl Device Intelligence iOS SDK. This repository
contains package manifests only — **no source**.

The manifests here are generated by the SDK's release pipeline. Each release is a git tag:

- `1.2.0` — a stable release; the default branch always reflects the newest one
- `1.2.0-rc.1` — a release candidate, published as a tag only

No stable version has been released yet. Once one is, this file is replaced by a generated
README carrying the current version and install instructions.
